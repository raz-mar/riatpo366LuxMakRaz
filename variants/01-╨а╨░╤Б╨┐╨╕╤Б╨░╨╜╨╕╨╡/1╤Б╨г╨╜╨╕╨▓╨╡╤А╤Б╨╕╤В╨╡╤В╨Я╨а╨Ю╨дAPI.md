# HTTP REST: 1С:Университет ПРОФ

Ниже перечислены HTTP-запросы, которые сервис расписания выполняет к публикации HTTP-сервисов 1С (`hs`). Способ вызова у всех одинаковый: **GET**, тела запроса нет.

Базовый хост, путь информационной базы, логин, пароль и таймаут задаются в таблице интеграций (`integration_endpoints`) и могут быть изменены в интерфейсе. Значения по умолчанию указаны рядом с каждым URL.

## Общие правила транспорта

| Параметр | Значение |
| --- | --- |
| Метод | `GET` |
| Тело | отсутствует |
| HTTP | 1.1 |
| Заголовок `Accept` | `application/json, text/plain, */*` |
| Прочие заголовки | содержимое `extra_headers` записи интеграции (если задано) |
| Авторизация | `Authorization: Basic <base64(username:password)>` при `auth_type = basic` |
| Пользователь по умолчанию | `SiteAPI` |
| Пароль | из настроек интеграции, в этом файле не приводится |
| Успех | HTTP `2xx` |
| Ошибка HTTP | любой статус вне `2xx`; сервис читает начало тела (до ~120 символов) |
| Формат тела | JSON-объект или JSON-массив. Перед первым `{` или `[` допускается произвольный префикс (сервис отрезает его) |
| Пустой ответ | ошибка разбора |
| Размер | скачивание целиком во временный файл; разбор в памяти — не более ~400 МБ, скачивание — не более 2 ГБ |

Оболочка ошибки (для ответов, где она есть):

```json
{
  "error": true,
  "message": "строка",
  "error_text": "строка"
}
```

Достаточно одного из полей `message` или `error_text`. При `"error": true` разбор содержимого не продолжается.

## `GET …/hs/volgmed_data/Department_University`

**URL по умолчанию**

```
http://10.128.240.232/university_volgmu/hs/volgmed_data/Department_University
```

**Query** — нет.

**Таймаут по умолчанию** — 1800 с.

**Ответ** — один JSON-объект дерева. Корень и каждый элемент `Подчиненные` имеют одну схему.

```json
{
  "TypeID": "строка | null",
  "GUID": "строка | null",
  "Представление": "строка",
  "ВидСтруктуры": "строка | null",
  "Характеристики": [
    {
      "КлючХарактеристики": "значение"
    }
  ],
  "Подчиненные": []
}
```

Поля узла:

| Поле | Тип |
| --- | --- |
| `TypeID` | строка или отсутствует |
| `GUID` | UUID-строка или отсутствует |
| `Представление` | строка |
| `ВидСтруктуры` | строка. Наблюдаемые значения: `Клинические и образовательные базы`, `Факультеты`, `Кафедры`, `Аудитории` |
| `Характеристики` | массив объектов. Каждый объект — набор строковых ключей и значений; объекты сливаются в одну карту |
| `Подчиненные` | массив узлов той же схемы (рекурсия) |

Ключи внутри `Характеристики`, которые сервис читает (если присутствуют):

| Ключ |
| --- |
| `Сокращенное наименование` |
| `Адрес` |
| `Фактический адрес` |
| `Базирующееся подразделение` |
| `Структурное подразделение` |
| `Количество посадочных мест` |
| `Количество мест` |
| `Тип помещения` |
| `Наименование комнаты` |
| `Номенклатура комнаты` |
| `Номенклатура комнат` |

Значения `Представление` на отдельных узлах, которые сервис обрабатывает как именованные ветки: `Клинические базы`, `Корпуса ВолгГМУ`.

Допустимо, что тело начинается не с `{` (сервис ищет первую фигурную скобку).

## `GET …/hs/volgmed_data/employees_v1`

**URL по умолчанию**

```
http://10.128.240.232/university_volgmu/hs/volgmed_data/employees_v1
```

**Query** — нет.

**Таймаут по умолчанию** — 1800 с.

**Ответ** — один из вариантов:

1. объект `{ "Сотрудники": [ … ] }` (допустим синоним `employees`);
2. JSON-массив сотрудников;
3. текст с префиксом до первого `{`, затем объект или массив как выше.

Элемент массива сотрудников:

```json
{
  "Фамилия": "строка",
  "Имя": "строка",
  "Отчество": "строка",
  "ФИО": "строка",
  "ДатаРождения": "YYYY-MM-DD…",

  "ГрафикРаботы": "строка",
  "УченаяСтепень": { "TypeID": "строка", "GUID": "строка", "Представление": "строка" },
  "УченоеЗвание": { "TypeID": "строка", "GUID": "строка", "Представление": "строка" },
  "ФизическоеЛицо": { "TypeID": "строка", "GUID": "строка", "Представление": "строка" },
  "Статус": "строка",
  "МедицинскийРаботник": true,
  "SPIN": "строка",
  "ORCID": "строка",
  "ResearcherID": "строка",
  "ScopusAuthorID": "строка",
  "Стаж": "строка",
  "СтажРаботы": "строка",
  "МедицинскийСтаж": "строка",
  "ОбразовательныйСтаж": "строка",
  "Работа": [],
  "СведенияОПовышенииКвалификацииИПереподготовке": [],
  "ПреподавательскаяДеятельность": [],
  "Награды": [],
  "НаучнаяДеятельность": [],
  "Услуги": [],
  "НаучныеИнтересы": "строка",
  "СвободнаяИнформация": "строка",
  "ВК": "строка",
  "Телеграмм": "строка",
  "Max": "строка",
  "ReaserchGate": "строка",
  "ЗаписьНаПрием": "строка"
}
```

Справочная ссылка (`УченаяСтепень`, `УченоеЗвание`, `ФизическоеЛицо`, поля внутри `Работа`):

| Поле | Тип |
| --- | --- |
| `TypeID` | строка |
| `GUID` | UUID-строка; значение `00000000-0000-0000-0000-000000000000` трактуется как отсутствие |
| `Представление` | строка; внешние кавычки снимаются |

Элемент `Работа[]`:

```json
{
  "GUID": "строка",
  "Состояние": "строка",
  "Ставка": "строка",
  "ТабельныйНомер": "строка",
  "ДатаОкончания": "YYYY-MM-DD…",
  "ЯвляетсяИО": "Да | Нет | true | false | 1 | 0 | …",
  "Преподаватель": "Да | Нет | …",
  "ВидЗанятости": "строка",
  "Должность": {
    "GUID": "строка",
    "Представление": "строка",
    "ВидППС": { "GUID": "строка", "Представление": "строка" },
    "ПКГД": { "GUID": "строка", "Представление": "строка" }
  },
  "Подразделение": { "GUID": "строка", "Представление": "строка" },
  "ВышестоящееПодразделение": { "GUID": "строка", "Представление": "строка" },
  "ТипДоговора": { "GUID": "строка", "Представление": "строка" }
}
```

`ДатаРождения` / `ДатаОкончания`: берутся первые 10 символов (`YYYY-MM-DD`). Значения, начинающиеся с `0001-01-01`, отбрасываются.

Логические поля `ЯвляетсяИО`, `Преподаватель`: строки `да` / `true` / `1` / `истина` и `нет` / `false` / `0` / `ложь` (без учёта регистра).

## `GET …/hs/Shedule/study_groups`

**URL по умолчанию**

```
http://10.128.240.232/university_volgmu/hs/Shedule/study_groups
```

**Query** — нет.

**Таймаут по умолчанию** — 600 с.

**Ответ**

```json
{
  "error": false,
  "groups": ["сЛ21-07", "мБ26-01"]
}
```

| Поле | Тип |
| --- | --- |
| `error` | boolean |
| `message` / `error_text` | строка при `error: true` |
| `groups` | массив. Синонимы: `Groups`, `группы` |

Элемент `groups[]`:

- строка; или
- объект `{ "name": "строка" }`.

При отсутствии массива сервис считает список пустым. Если поле есть, но это не массив — ошибка разбора.

## `GET …/ru/hs/campus/StudentRating`

**URL по умолчанию**

```
http://10.128.240.232/university_volgmu/ru/hs/campus/StudentRating
```

**Query** — нет.

**Таймаут по умолчанию** — 600 с.

**Ответ**

```json
{
  "error": false,
  "generated_at": "строка",
  "date_slice": "строка",
  "data": []
}
```

| Поле | Тип |
| --- | --- |
| `error` | boolean |
| `message` / `error_text` | строка при `error: true` |
| `generated_at` | строка |
| `date_slice` | строка |
| `data` | массив объектов. Синонимы: `Data`, `students` |

Элемент `data[]`:

| Поле | Тип |
| --- | --- |
| `gradebook` | произвольный |
| `status` | строка |
| `subdivision` | строка |
| `speciality` | строка |
| `study_form` | строка |
| `education_level` | строка |
| `course` | строка |
| `group` | строка |
| `academic_year` | строка |
| `form` | строка |
| `citizenship` | строка |
| `preliminary_gia_rating` | число или строка с числом |
| `has_gia_rating` | произвольный |

При отсутствии `data` массив считается пустым; `generated_at` и `date_slice` с корня всё равно читаются. Если `data` задано и это не массив — ошибка разбора.

Вызов выполняется независимо от `study_groups` (два отдельных GET). Неуспех одного из двух не отменяет второй.

## `GET …/hs/Shedule/list_curricula`

**URL по умолчанию**

```
http://10.128.240.232/university_volgmu/hs/Shedule/list_curricula
```

**Query** — нет.

**Таймаут по умолчанию** — 600 с.

**Ответ**

```json
{
  "error": false,
  "data": []
}
```

| Поле | Тип |
| --- | --- |
| `error` | boolean |
| `message` / `error_text` | строка при `error: true` |
| `data` | массив объектов. Синонимы: `Data`, `curricula` |

При `error: true` — ошибка. При отсутствии массива — пустой список. Если поле есть и это не массив — ошибка разбора.

Элемент `data[]` (имена в snake_case или camelCase равнозначны):

| Поле | Синоним | Тип |
| --- | --- | --- |
| `plan_number` | `planNumber` | строка, обязательное для включения строки |
| `speciality` | — | строка |
| `academic_year` | `academicYear` | строка |
| `academic_year_start` | `academicYearStart` | дата; берутся первые 10 символов `YYYY-MM-DD` |
| `academic_year_end` | `academicYearEnd` | дата, тот же формат |
| `study_form` | `studyForm` | строка |
| `education_level` | `educationLevel` | строка |
| `plan_type` | `planType` | строка |
| `faculty` | — | строка |
| `is_posted` | `isPosted` | boolean; отсутствие или любое значение кроме `false` считается истиной |

Повторяющиеся `plan_number` сводятся к одной записи (последняя по ходу массива).

## `GET …/hs/Shedule/disciplines_departments`

**URL по умолчанию**

```
http://10.128.240.232/university_volgmu/hs/Shedule/disciplines_departments?number={planNumber}
```

**Query**

| Имя | Обязательный | Значение |
| --- | --- | --- |
| `number` | да | строка номера плана (`plan_number` из `list_curricula`) |

Сервис вызывает этот URL **отдельно для каждого** значения `number`. Параметр дописывается к сохранённому URL через `URLSearchParams`.

**Таймаут по умолчанию** — 120 с (на один запрос).

**Ответ**

```json
{
  "error": false,
  "number": "000004748",
  "data": []
}
```

| Поле | Тип |
| --- | --- |
| `error` | boolean |
| `message` / `error_text` | строка при `error: true` |
| `number` | строка (может совпадать с query `number`) |
| `data` | массив объектов. Синоним: `Data` |

При `error: true` — ошибка для данного `number`. При отсутствии массива — пустой список. Если поле есть и это не массив — ошибка разбора.

Элемент `data[]`:

| Поле | Тип |
| --- | --- |
| `semester_number` | целое число |
| `semester` | строка |
| `discipline` | строка |
| `load` | строка |
| `row_type` | строка |
| `quantity` | число |
| `unit` | строка |
| `type_record` | строка |
| `subdivision` | строка |
| `plan_number` | строка (в ответе может быть; query `number` для разбора приоритетен) |
| `academic_year` | строка |
| `specialization` | строка |

Строка без `discipline` или без `load` пропускается.

Пример:

```json
{
  "error": false,
  "number": "000004748",
  "data": [
    {
      "semester_number": 1,
      "semester": "Первый семестр",
      "discipline": "Анатомия",
      "load": "Лекционные занятия",
      "row_type": "Нагрузка",
      "quantity": 6,
      "unit": "Часы",
      "type_record": "Б1.О.12",
      "subdivision": "Кафедра анатомии",
      "plan_number": "000004748",
      "academic_year": "2025 - 2031",
      "specialization": "Лечебное дело"
    }
  ]
}
```
